# Yashwanth Ji K — Portfolio

A single-page developer portfolio styled as a code editor: a typed "about.js" hero,
a syntax-highlight accent palette, a scroll-animated education timeline, and a
terminal-style contact panel.

## Files
- `portfolio.html` — page markup
- `portfolio.css` — design system + animations
- `portfolio.js` — typing effect, scroll reveals, timeline fill, navbar/back-to-top behavior
- `assets/` — profile photo, icons, resume PDF

## Content source
All copy (education, skills, projects, contact) is pulled directly from the resume
so the two stay in sync. Update `assets/Karnekota_Yashwanth_Resume.pdf` whenever the
resume changes, and keep this file's content matching it.

## Run it
Just open `portfolio.html` in a browser — no build step needed.
